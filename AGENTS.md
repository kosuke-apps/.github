# kosuke-apps/.github

Organization-level community files of the GitHub organization `kosuke-apps` (profile README, security policy,
contributing guide, issue templates). Workspace rules are in `~/Developer/AGENTS.md`; the licensing and publication
rules there ("Licensing and provenance") apply to everything written here.

- Files here are public and apply to every app repository. Keep them short, in English, and free of personal data
  (no personal email address; reports go through GitHub's private reporting).
- The apps table in `profile/README.md` is updated when an app repository is published or retired.
- `LICENSE` cannot be inherited by other repositories; each app carries its own.
- Check changes with: `git diff`, then read the rendered files on GitHub after pushing.
