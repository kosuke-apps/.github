# Contributing

Issues are welcome: bug reports, ideas and questions. Please use the issue template of the repository.

Pull requests are not accepted for now. Each project is kept under a single copyright holder, which keeps the licence
simple and lets the rights move to a company later. If this changes, contributions will need a sign-off under the
[Developer Certificate of Origin](https://developercertificate.org/).

Each app does one thing. A request fits best when it makes that one thing better.

Please do not put personal data, recordings or transcripts in issues, screenshots or logs.
