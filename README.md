# .github

Organization-level files of [kosuke-apps](https://github.com/kosuke-apps). GitHub uses them as defaults for every
repository of the organization that does not have its own copy.

| File | Purpose |
|---|---|
| `profile/README.md` | The organization's profile page |
| `SECURITY.md` | How to report a vulnerability |
| `CONTRIBUTING.md` | How to contribute (issues yes, pull requests not for now) |
| `SUPPORT.md` | Where to ask questions |
| `.github/ISSUE_TEMPLATE/` | Bug report and feature request forms |

`LICENSE` files cannot be inherited; each repository carries its own.
