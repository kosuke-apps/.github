## Principles

<table>
  <tr>
    <td width="25%" valign="top"><b>One job</b><br>An app does one thing and does it well. No bundled extras.</td>
    <td width="25%" valign="top"><b>On your device</b><br>Everything runs locally. No accounts, no analytics, no ads, no servers of ours.</td>
    <td width="25%" valign="top"><b>Only what it needs</b><br>Each permission is asked for when needed, with the reason.</td>

  </tr>

## Install

<details>
<summary><b>Mac apps (<code>.dmg</code>)</b></summary>

1. Open the app's **Releases** page and download the `.dmg`.
2. Open it and drag the app to **Applications**.
3. The first time, macOS asks for confirmation: releases are signed but not notarized. Open
   **System Settings → Privacy & Security** and choose **Open Anyway**.
4. Optional: check the download with `shasum -a 256 -c <file>.sha256`.

</details>

<details>
<summary><b>iPhone apps (<code>.ipa</code>)</b></summary>

The iPhone apps are not in the App Store. Each release is an unsigned `.ipa`, on purpose: install it with a sideloading
tool (for example AltStore or Sideloadly) that signs it with your own Apple ID. Check the file first with
`shasum -a 256 -c <file>.sha256`. Each README also explains how to build the app from source.

</details>
